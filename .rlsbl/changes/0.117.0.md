## 0.117.0

The scrub flow reads safegit's interface_version 2 envelope and requires safegit 0.28.0 or later.

### Breaking

- **BREAKING: `rlsbl release scrub` now requires safegit 0.28.0 or newer.** safegit 0.28.0 is built on the framework release whose machine-mode envelope declares `interface_version` 2 -- the document grew a `writes` member (null on every scrub command, which rlsbl ignores). rlsbl reads version 2 only: an envelope declaring version 1, from a safegit before 0.28.0, is refused by name with the version to install, exactly as a pre-envelope safegit's bare JSON already was. There is no dual support and no fallback parse. Remedy: upgrade safegit to 0.28.0 or later (`go install github.com/smm-h/safegit@v0`).

### Fixes

- **The documented `--json` envelope example matches what rlsbl emits.** The machine-output page still showed `interface_version` 1 and omitted the `writes` member; rlsbl has emitted the version 2 envelope since it moved onto the current framework release. A consumer copying the example as its expected shape now sees the real one.
