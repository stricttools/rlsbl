When a sub-project has `"targets": []` in its `.rlsbl/config.json`, `detect_targets()` returns empty, which means `_build_project_template_vars()` produces no template variables during `rlsbl monorepo sync`. This leaves `{{pypi.minRequiredPython}}` unresolved in generated CI workflows. Either `detect_targets()` should fall back to auto-detection when the list is empty, or sync should resolve variables from the workspace root config when per-project variables are empty.
