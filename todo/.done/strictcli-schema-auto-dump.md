# Auto-detect strictcli projects and dump schema during release

## Context

strictcli projects can generate `.strictcli/schema.json` via `--dump-schema`. Currently this would need to be wired manually into each consumer's pre-release hook. rlsbl should detect strictcli usage and do this automatically.

## Proposed behavior

During `rlsbl release`, after pre-checks but before version bump:

1. Detect if the project uses strictcli:
   - Python: check `pyproject.toml` dependencies for `strictcli`
   - Go: check `go.mod` for `github.com/smm-h/strictcli`
2. If detected, run the CLI entry point with `--dump-schema`
   - Python: `uv run <entry_point> --dump-schema`
   - Go: `go run . --dump-schema`
3. If `.strictcli/schema.json` was created or updated, commit it with `Autogenerated: true` trailer

This way consumers get schema generation for free without any per-project hook setup.

## Effort

Small-medium. Detection is straightforward (already done for target detection). Running the entry point needs the entry point name (from pyproject.toml `[project.scripts]` or go build).
