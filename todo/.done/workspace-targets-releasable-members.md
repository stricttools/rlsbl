The `workspace-targets` check iterates every `[[projects]]` entry and fails if any returns zero targets. But in monorepos with `[[releasables]]`, member projects delegate their release target to the releasable level (targets are configured at the workspace root, not on individual members). The check should skip projects with `releasable = "<name>"` and instead verify the releasable root has targets. `project_is_releasable()` is already imported in workspace.py but never used.
